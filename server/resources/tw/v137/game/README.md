# Stella Sora TW Recovered Game Data

This dataset was generated by statically rebuilding and decoding resources from a locally
installed Stella Sora TW client. The snapshot corresponds to client `1.13.0` and resource
version `137`.

## Entry points

- `index.json`: top-level inventory and statistics.
- `categories/index.json`: feature-oriented classification index.
- `bin/<Table>.json`: decoded source fields and values.
- `readable/<Table>.json`: source values with localized text attached under `_localized`.
- `language/`, `bubble/`, and `dirty_words/`: supporting files recovered from local archives.
- `source.json`, `evidence/`, and `validation/`: provenance, hashes, field mappings, and checks.

## Reference cross-checking

The Hiro420/StellaSoraData repository was used only as a candidate source for table names,
hotfix field schemas, and validation. Candidate archive paths had to match local XXH64 values,
and table contents were independently decoded from local protobuf bytes.

## Format conventions

JSON files use UTF-8 and two-space indentation. Field names preserve the spelling used by the
game schema. A table can belong to more than one feature category; category files are indexes
and do not modify the original decoded tables.
